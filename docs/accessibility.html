Information

Accessibility

I aim to make this website accessible. The site uses structured headings and page landmarks, visible keyboard focus, text alternatives for images, and keyboard-operable filters and video controls.

01 Review

Accessibility review

The site’s page structure and keyboard navigation were checked in Chrome. Screen-reader testing and testing on real mobile devices have not yet been performed.

02 Contact

Report an accessibility barrier

If you encounter an accessibility barrier, please email labibs@wgalil.ac.il. Include the page URL, what you were trying to do, your device and browser, and any assistive technology you use.

03 Events

Speaking engagements

Event organizers select the venue and arrange its accessibility. Please contact the event organizer about access to a specific venue or event accommodations.
