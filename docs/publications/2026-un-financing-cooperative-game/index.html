Cooperative Game-Theoretic Framework for Sustainable UN Financing: An Application to Global Public Goods Provision

Labib Shami and Teddy Lazebnik

Economies 14(7), 263 Open access

Read the article Earlier preprint (arXiv:2602.15062)

Summary

Develops a cooperative game-theoretic framework for financing global public goods and applies it to United Nations funding: each member state's contribution is priced according to the benefit it derives, and agent-based simulations calibrated to observed contribution patterns compare this design with a non-cooperative benchmark.

This summary was written for this website from the published abstract. The publisher’s abstract and full text are the authoritative versions. No full text is reproduced here.
