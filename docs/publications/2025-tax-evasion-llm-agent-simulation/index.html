Investigating Tax Evasion Emergence Using Dual Large Language Model and Deep Reinforcement Learning Powered Agent-based Simulation

Teddy Lazebnik and Labib Shami

arXiv Preprint

Read on arXiv

Summary

Asks how tax evasion emerges in a population in the first place, rather than taking it as given. The study uses an agent-based simulation whose agents are driven by a large language model and deep reinforcement learning.

This summary was written for this website from the published abstract. The publisher’s abstract and full text are the authoritative versions. No full text is reproduced here.
