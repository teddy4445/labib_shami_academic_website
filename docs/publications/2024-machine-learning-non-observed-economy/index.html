Implementing Machine Learning Methods in Estimating the Size of the Non-observed Economy

Labib Shami and Teddy Lazebnik

Computational Economics 63(4), 1459–1476

Read the article

Summary

Shows that machine-learning methods, notably a random forest, estimate currency demand more accurately than the standard currency-demand regressions, improving estimates of the size of unregistered economic activity.

This summary was written for this website from the published abstract. The publisher’s abstract and full text are the authoritative versions. No full text is reproduced here.
